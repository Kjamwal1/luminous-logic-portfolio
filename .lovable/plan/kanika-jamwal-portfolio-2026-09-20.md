# Kanika Jamwal Portfolio

## Build
- Create a polished dark portfolio centered on Kanika’s identity as a web developer, product designer, and computer-vision builder.
- Feature the uploaded portrait prominently and include CareerHub and the Human Detection System alongside the other résumé projects.
- Add refined 3D-inspired depth, motion, custom cursor details, and responsive interactions without compromising readability or mobile performance.
- Present experience, selected work, technical skills, education, certifications, and direct contact details in one cohesive experience.

## Visual direction
- Use a graphite-black studio aesthetic with sharp typography, electric cyan accents, subtle lime highlights, fine grid lines, and restrained glass/metal surfaces.
- Favor asymmetric editorial composition over generic cards, with a large portrait, numbered work index, and timeline-led experience section.

## Technical details
- Store the uploaded photo and résumé as hosted project assets.
- Build with React, semantic Tailwind design tokens, accessible controls, and lightweight CSS 3D transforms.
- Add route-specific social metadata and verify desktop and mobile rendering in the browser.
